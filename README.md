# Интернет-дүкенді тестілеу
### Учебный проект по тестированию веб-приложений

## 1. Описание проекта

**Название проекта:** MarketShop

**Тема:** «Тестирование интернет-магазина по образцу Яндекс Маркета».

MarketShop — учебное веб-приложение, имитирующее работу интернет-магазина. Проект разработан для изучения принципов создания и тестирования веб-приложений.

Пользователь может просматривать товары, искать их по названию, фильтровать по категориям, добавлять товары в корзину, изменять количество товаров и оформлять демонстрационный заказ.

Также реализован интерфейс регистрации и авторизации пользователей.

**Важно:** проект является учебной имитацией интернет-магазина. Он не связан с официальным Яндекс Маркетом и не обрабатывает реальные платежи.

## 2. Цель проекта

Цель проекта — получить практические навыки разработки и тестирования веб-приложений.

В рамках проекта изучаются:
- функциональное тестирование;
- тестирование пользовательского интерфейса;
- проверка форм регистрации и авторизации;
- тестирование поиска и фильтрации товаров;
- проверка работы корзины;
- тестирование оформления заказа;
- работа с инструментами разработчика браузера;
- основы API-тестирования с использованием Postman.

## 3. Используемые технологии

| Технология | Назначение |

## 4. Функциональные возможности

### 4.1. Каталог товаров

Пользователь может:
- просматривать список товаров;
- видеть название, категорию, описание и цену;
- искать товары по названию;
- фильтровать товары по категориям;
- видеть количество найденных товаров.

### 4.2. Корзина

Реализованы следующие возможности:
- добавление товара в корзину;
- увеличение количества товара;
- уменьшение количества товара;
- удаление товара из корзины;
- автоматический подсчёт общей стоимости;
- сохранение содержимого корзины после обновления страницы.

### 4.3. Регистрация и авторизация

Пользователь может:
- открыть форму регистрации;
- создать демонстрационный аккаунт;
- войти с помощью email и пароля;
- получить сообщение об ошибке при вводе неправильных данных;
- выйти из аккаунта;
- сохранить состояние входа после обновления страницы.

**Ограничение:** авторизация реализована на стороне браузера и предназначена только для учебных целей. Серверная авторизация, база данных пользователей и безопасное хеширование паролей пока не реализованы.

### 4.4. Оформление заказа

Пользователь может:
- открыть форму оформления заказа;
- указать имя;
- ввести номер телефона;
- указать адрес доставки;
- подтвердить демонстрационный заказ;
- получить сообщение об успешном оформлении.

Заказ не отправляется на сервер, а реальные платежи не выполняются.

## 6. Установка и запуск

### Требования

Перед запуском необходимо установить:
- Node.js;
- npm;
- Visual Studio Code или другой редактор кода.

### Шаг 1. Открыть папку проекта

Откройте терминал в папке `yandex-market-test`.

### Шаг 2. Установить зависимости

Выполните команду:

```bash
npm install
```

### Шаг 3. Запустить приложение

Выполните:

```bash
npm run dev
```

После запуска Vite выведет локальный адрес приложения. Обычно это:

```text
http://localhost:5173/
```

Откройте этот адрес в браузере.

Для остановки сервера разработки нажмите `Ctrl + C` в терминале.

## 8. API-тестирование

Для изучения API-тестирования можно использовать Postman.

В рамках учебной работы можно проверить:
- GET — получение данных;
- POST — создание записи;
- PUT — обновление записи;
- DELETE — удаление записи;
- коды HTTP-ответов;
- структуру JSON;
- обработку ошибок.

На текущем этапе интернет-магазин использует локальный массив товаров и не имеет собственного backend API. Поэтому для первоначальной практики можно использовать открытый тестовый API, например JSONPlaceholder.

Запросы к тестовому API не означают, что интернет-магазин уже подключён к серверу.

## 9. Известные ограничения

На текущем этапе проекта:
- товары хранятся в JavaScript-массиве;
- собственный сервер и база данных не подключены;
- данные демонстрационной авторизации хранятся в `localStorage`;
- пароли не хешируются;
- оформление заказа не отправляет данные на сервер;
- онлайн-оплата не реализована;
- API-тестирование выполняется отдельно от основного приложения.

Эти ограничения необходимо учитывать при оценке результатов тестирования.

## 10. Ожидаемый результат

В результате выполнения проекта создаётся учебный интернет-магазин с основными пользовательскими функциями.

Проект позволяет изучить жизненный цикл тестирования веб-приложения: от определения требований и составления тест-кейсов до проверки функциональности, фиксации обнаруженных ошибок и подготовки отчёта о тестировании.

## 11. Заключение

В ходе работы над проектом изучаются основы разработки интерфейсов на React, применение JavaScript для управления состоянием приложения, использование CSS для оформления страниц и `localStorage` для локального сохранения данных.

Основное внимание уделяется тестированию функциональности интернет-магазина, проверке пользовательских сценариев и подготовке документации, необходимой для оценки качества веб-приложения.
